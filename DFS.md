Algorithm: Depth First Search (Recursive)

Step 1: Start.
Step 2: Create an empty set called Visited.
Step 3: Call DFS(Start Node).
Step 4: In DFS(Node):
        a. If the node is not visited:
             i. Display the node.
            ii. Mark the node as visited.
           iii. For each neighboring node:
                    Call DFS(neighbor).
Step 5: Stop.
