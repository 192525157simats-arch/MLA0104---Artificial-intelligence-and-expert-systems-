Algorithm: Breadth First Search (BFS)

Step 1: Start.
Step 2: Create an empty list called Visited.
Step 3: Create an empty Queue.
Step 4: Insert the starting node into Visited and Queue.
Step 5: While the Queue is not empty, do:
        a. Remove the front node from the Queue.
        b. Display the node.
        c. For each adjacent node:
             i. If the node is not visited:
                - Mark it as visited.
                - Insert it into the Queue.
Step 6: Stop.
